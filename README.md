## 🔄 Progressive Awakening System

漸進式靈性引導旅程，透過三個階段帶領訪者從數據衝擊走向福音：

- **Lv 0 (AWAKENING)**: 死亡數字大紅字 — `index.html`
- **Lv 1 (AWARENESS)**: 生死記錄儀 — `monitor03E.html`
- **Lv 2 (GOSPEL)**: 福音旅程 — `GoodNews.html`
