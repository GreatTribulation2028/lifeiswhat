## 頁面結構討論記錄

### 頁面流程設計（用戶需求）

用戶提出的核心頁面流程：

```
01 Tribulation Journey.html（只保留大紅字死亡數字跳動）
    ↓
02 index.html（點擊後直接跳到 03 monitor，不是「生死之間」頁面）
    ↓
03 monitor.html（最下方加入「IF IT WERE YOU / 如果是你」區塊）
    ↓（點擊後顯示福音橋 + 五色福音影片選擇）
    ↓（播放進度條 + 4分30秒後顯示三個選項）
        ├─→ pCloud 聖經資訊
        ├─→ 返回門戶
        └─→ 了解世界的末了
```

### 死亡數字顯示邏輯

```
① 年度全球死亡總數（大紅字，心跳動效）
② 換算：每分鐘平均死亡人數
③ 自 2019-12-01 COVID-19 起累計死亡總數
④ 需有可靠數據來源（WHO/UN 等）
⑤ 「這是真的嗎？」→ 改為「查看」按鈕
```
